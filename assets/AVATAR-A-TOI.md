# Ton avatar à toi

Dépose ici un fichier nommé exactement **`perso-custom.glb`**.
Le jeu le prend automatiquement à la place de l'avatar par défaut.
Aucun code à toucher. S'il n'est pas là, le défaut reste.

## Où fabriquer un avatar (gratuit, ~2 min)

- **Réaliste (façon Skyrim / RPM)** : readyplayer.me → crée ton perso →
  bouton "Download .glb". Il arrive en pose T (sans animation), mais c'est TON visage.
- **Réaliste + animé** : mixamo.com (compte Adobe gratuit) → choisis un
  personnage → une animation "Idle" → Download → Format **glTF (.glb)**.
- **Anime (façon Solo Leveling)** : vroid.com → VRoid Studio → export.
  (VRoid sort du .vrm ; pour le .glb, exporte en glTF ou dis-le-moi, j'ajoute le lecteur .vrm.)

Renomme le fichier en `perso-custom.glb`, pose-le dans ce dossier, recharge la page.
